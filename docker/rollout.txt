# Declarations for zero-downtime rollouts (docs/deployment.md, section 8; docs/project-foundation.md, Migration
# contract). One line each, "<kind> <name>", kind expand or breaking, added by the change that brings it. Only add
# lines; a name never repeats.
#
# - Every migration under apps/server/drizzle has exactly one line with its tag. expand: every statement is one of a
#   few exact shapes (new tables in drizzle-kit's layout, indexes on them, foreign keys between them), so it locks nothing the
#   running release uses (apps/server/src/rollout.test.ts checks the statements). Anything that touches an existing
#   table is breaking, adding a column included; a new side table rolls out instead.
# - "breaking pg-boss-schema-<N>" for each pg-boss schema number; the check fails until the installed one has its line.
# - "breaking <name>" for any other change a release since maane.rollout-from cannot run beside: a job the older
#   worker reads wrongly, stored data whose meaning changes, a new required variable in app.env, a changed file under
#   docker/clamav/. Write a host step in CHANGELOG.md too: the release notes come from it.
#
# scripts/release.sh labels each image maane.rollout-from with the oldest release that already had the newest breaking
# line of the image, or with the image's own version when a breaking line is new.
#
